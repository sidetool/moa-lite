# 자막, 번역과 스킵

로컬 파일·확장 자막·온라인 후보를 선택할 수 있다. ASS는 JASSUB, VTT와 변환된 SRT/SMI는 브라우저 자막으로 표시한다. 자막 높이·싱크·선택은 기기·세션 정책에 따라 보존한다. 제목·시즌·회차와 제작자 정보를 이용해 후보를 찾지만 판본·편집·통합 회차의 일치를 보장하지 않는다. 사용자가 확인하고 선택한다.

온라인 검색은 Anissia/AniList 메타데이터, 자막 제작자 페이지의 수집 어댑터와 Jimaku를 사용할 수 있다. 이는 확장 저장소의 기본 등록과 별개이며 외부 네트워크 조회·파일 다운로드를 수행할 수 있다. 첨부 파일은 크기·경로·ZIP 항목·타임아웃을 제한한다. 공개 URL은 재배포·번역 허가를 뜻하지 않는다.

Gemini 번역은 관리자가 키와 활성 상태를 설정한 경우 사용한다. 자막 본문·제목·회차·문맥이 외부 API로 전송되고 요청 비용·사용량 한도가 적용될 수 있다. 부분 완료·재시도·우선 구간 처리와 저장된 번역 트랙을 제공하지만 번역 품질·완료 시간을 보장하지 않는다. 원자막과 번역을 이용할 권리는 사용자가 확인한다.

스킵 마커는 AniSkip 조회와 로컬 시즌 오디오의 반복 구간 분석을 구분한다. 외부 마커는 회차·길이가 맞아도 다른 판본에서 틀릴 수 있고 로컬 지문도 반복 장면을 오탐할 수 있다. 현재 영상에서 확인한 뒤 사용한다. 저작권이 확인된 합성 PCM/영상으로 개발 테스트를 작성한다.

수집한 자막·번역·마커·메타데이터 캐시는 앱 데이터다. 소프트웨어의 GPL 라이선스가 그 콘텐츠나 외부 API 데이터의 재배포 권한을 부여하지 않는다.

## moa-lite 검색 개선 (2026-10-05)

MOA 공개 커밋 `bf0a484`의 검색·수집 개선을 반영했다. 공개 제작자 디렉터리 탐색, RSS·검색 다음 페이지, 버튼·스크립트에 있는 첨부 URL, 완결 표기 처리, 알려진 게시글 주소의 중복 배제 수정을 공유한다. 작품별 예외를 새로 추가하지 않았다. 자동 싱크 검사·보정 및 해당 설정은 가져오지 않았다. 기존 수동 싱크와 Gemini 번역은 유지한다.

Lite의 차이:

- 검색은 기존 Vercel 함수에서 실행한다. 접속 차단·시간 초과는 원본 URL·예외 메시지 없이 기존 자막 메뉴의 설명으로 전달한다.
- 같은 기기·프로필·회차·검색 조건의 정상 완료 결과는 5분간 재사용한다. 부분 응답·실패·변경한 검색 조건은 다시 요청한다. 원문은 기존 IndexedDB 저장 범위에 머물고 Redis에 추가하지 않는다.
- ZIP 처리는 유지하며 7z/RAR/TAR는 서버 전용 `libarchive-wasm@1.2.0` Worker로 읽는다. OS 프로그램 설치나 브라우저용 디코더 다운로드는 필요 없다. 일반 자막·ZIP 요청은 이 Worker를 띄우지 않는다.
- 압축 처리는 동시에 최대 2개, 8초 제한이며 작업 후 Worker를 종료한다. Lite 검색은 응답 2MiB, 압축 입력·선언된 총 해제 크기 4MiB, 기본 300항목 한도를 적용한다. 경로 이동·링크·암호화된 내용은 수집하지 않고 원문을 디스크에 풀지 않는다.

이번 검증은 합성 자막과 로컬 API로 수행했다. 공개 사이트별 검색 성공률이나 실제 Vercel 운영 배포를 확인했다는 뜻은 아니다.
